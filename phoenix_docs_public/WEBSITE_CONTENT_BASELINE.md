# Website Content Baseline (Public)

This document is the public source of truth for high-level website copy in the public website frontend.

## Approved public claims by page

### Home

- Phoenix supports documented Ask/Plan/Agent workflows.
- User approvals, previews, and visible action boundaries are core UX principles.
- The editor is open source, with optional managed service lanes.
- For the current web MVP, access is account-gated and scoped to chat + PixelPen prototype workflows.

### Pricing

- Website copy may describe usage lanes (BYOK, optional managed service lanes, offline/local-only).
- If detailed public pricing tables are not published in public docs, website pricing copy should avoid presenting speculative tier pricing as final.

### Demos

- Website demo content should reference published resources only (for example, official Godot demo resources and public Phoenix docs).
- Do not present fabricated customer/media demo claims.
- If web editor parity is incomplete, demo copy should explicitly label the experience as an MVP prototype.

### Reviews

- If testimonials are not published, website copy should explicitly say reviews are not yet published.

### Blog

- If release posts are not published, website copy should explicitly say blog posts are not yet published.

### Docs

- Docs links should target current approved docs endpoints.
- Godot documentation/branding attribution must remain intact.

### Donate

- Donation copy must include this disclosure: **10% of gross donations are allocated to Godot Foundation support.**
- Donation and billing operations are backend-authorized; the public frontend is not the billing system of record.
