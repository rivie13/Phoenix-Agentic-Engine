# Phoenix Docs (Public)

This folder contains **public-facing** documentation for Phoenix Agentic Engine.

Phoenix is a fork of [Godot Engine](https://github.com/godotengine/godot) that focuses on adding an agentic, IDE-style assistant workflow inside the editor while keeping core engine changes minimal.
